# explorer-tracker-addon
Legal automatic tracking addon for Audiopixie's Explorer% tracker for Blue Prince


# To use
Download Audiopixie's Explorer% tracker at https://github.com/AudioPixie/BPExplorerTracker

Run the python script that will place the files in the right spot so that you can check the automatic box on the tracker

Run the tracker and check the automatic box

YOU DO NOT HAVE TO PIP INSTALL WATCHDOG it just makes it update like 5 seconds faster
